# priamos-weekly: 주간 실적 점검 → 설정 조정 → 보고

사용자는 "인스타 올라간 글들 조회수나 하트들을 분석해서 어떤 방식으로 인스타를 꾸려야 할지 고민해서 고쳐야지",
"넌 이제부터 마케팅 팀장이야"라고 맡겼다. 이 점검은 그 일을 매주 반복한다.
근거는 이 계정 자신의 숫자다(ig-audit 원칙). 일반론은 참고만 한다.

## 1. 숫자 뽑기

```bash
cd /home/user/priamos301-cards && git pull origin main
python3 tools/insights.py > $TMP/ins.jsonl          # 저장소에 넣지 않는다(비공개 지표)
python3 tools/weekly_report.py $TMP/ins.jsonl --days 7
```
`$TMP` 는 세션 scratchpad. 보고서는 릴스를 배수(조회 ÷ 릴스 조회 중앙값)와 공유/도달 순으로 정렬하고, 분류·게시 시각·훅·배경음별로 묶는다.

## 2. 읽는 순서 (ig-audit 와 같다)

1. **배수 2배 이상인 릴스**와 **0.8배 이하 릴스**를 나란히 놓고 차이를 찾는다: 훅 공식, 분류(주제), 그림, 길이, 평균 시청.
2. **평균 시청 ÷ 릴스 길이**(시청 비율). 30% 아래면 훅 뒤가 지루하다는 뜻이다.
3. **공유/도달, 저장/도달**. 공유는 가장 강한 신호다.
4. **카드(이미지·캐러셀)의 도달**. 팔로워가 적을 때 단일 이미지는 거의 퍼지지 않는다.
5. **게시 시각**은 맨 마지막에, 앞의 것으로 설명이 안 될 때만 본다. 표본이 슬롯당 5개 미만이면 시각은 바꾸지 않는다.

## 3. 고쳐도 되는 것 (범위 안에서만, 한 번에 2가지까지)

| 항목 | 고치는 곳 | 범위 |
|---|---|---|
| 게시 시각 5개 | `update_trigger` 의 cron (예약 "자동 뉴스 게시") | 06:00~24:59 사이, 하루 5회 유지. 분은 정각·30분을 피한다 |
| 주제 비중 | priamos-daily `## 1. 뉴스 고르기` 의 "주제 우선순위" | 사실 확인·제외 규칙은 손대지 않는다 |
| 훅 공식 우선순위 | priamos-daily 훅 공식 표 아래 "우선" 줄 | hookscore 기준(55점)은 낮추지 않는다 |
| 릴스 길이·자막 장면 수 | priamos-daily 릴스 spec 예시 | 9~16.5초 |
| 카드 형식 | priamos-daily `## 4. 렌더` | 단일 카드 / 캐러셀 |

한 주에 두 가지까지만 바꾼다. 무엇이 효과였는지 다음 주에 구분할 수 있어야 한다.
바꾼 내용은 `log/weekly.md` 에 날짜, 근거(공개 지표인 조회수 중앙값·배수만), 바꾼 것, 다음 주에 볼 숫자를 적는다.
도달·저장·공유 같은 비공개 지표는 저장소에 적지 않고 보고에만 쓴다.

## 2-1. 릴스 칸 전용 전환 효과 (2026-11-02 점검부터)

2026-10-28 16:40 KST 이후 릴스는 `share_to_feed=false`(릴스 칸에만)로 올라간다. 전환 전 7일과 전환 후 릴스의 조회 중앙값·도달 중앙값을 나눠 비교해 보고에 적는다. 전환 후 중앙값이 전보다 30% 넘게 떨어지고 다른 설명(주제·훅·시각)이 없으면, 사용자에게 다시 게시물 칸에도 올릴지 묻는다(직접 되돌리지 않는다).

## 3-1. 저장소 용량 점검

`du -sh .git` 로 저장소 크기를 본다. 게시물 그림·영상이 공개 저장소에 쌓이고, GitHub 는 1GB 미만을 권장하고 5GB 미만을 강하게 권한다.
700MB 를 넘으면 보고에 적고, 이미 게시된 파일을 히스토리에서 지우는 정리(강제 push가 필요한 되돌릴 수 없는 작업)를 사용자에게 제안한다. 사용자가 승인하기 전에는 하지 않는다.

## 3-2. AI 안내 확인

`GET /me?fields=biography` 로 프로필 소개에 "AI" 안내 줄(현재 "일러스트는 AI로 제작")이 남아 있는지 본다. 게시물에는 AI 표시를 넣지 않기로 했기 때문에 이 한 줄이 유일한 안내다. 없어졌으면 보고에서 사용자에게 알린다(프로필은 직접 고치지 않는다).

## 4. 하지 않는 것

하루 게시 수 변경, 게시물 삭제, 프로필 변경, 댓글·DM 자동 작성, 유료 결제, 사실 확인 규칙 완화.
댓글이 달렸으면 `ig-reply` 스킬로 답글 초안만 만들어 보고에 붙이고, 사용자가 승인해야 단다.
프로필 개선(이름 칸, 소개, 링크, 고정 게시물)은 `ig-profile` 로 점수와 고칠 문구를 만들어 사용자에게 제안만 한다.
